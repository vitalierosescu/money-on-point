# ADR-0001: Canonical Design System

## Decision

The canonical design guidance lives in `ai/current/design-system.md`, with implementation tokens in `app/globals.css` and Tailwind mappings in `tailwind.config.ts`.

## Reason

The repo previously had conflicting guidance across `CLAUDE.md`, `.impeccable.md`, and ad hoc redesign notes. A single canonical design doc reduces agent drift.
